# Imágenes pendientes — Perrustingo

Estilo unificado para TODAS: **render 3D estilo clay/juguete (tipo emoji 3D de iOS / Pixar soft)**, iluminación de estudio suave, formas redondeadas, fondo **sólido de un color** (se recorta en círculo, así que el sujeto debe estar centrado con margen). Formato **PNG cuadrado, 512×512 o superior**. Al guardar cada archivo en su ruta, el sitio lo usa automáticamente (hoy muestra un dibujo SVG de respaldo).
